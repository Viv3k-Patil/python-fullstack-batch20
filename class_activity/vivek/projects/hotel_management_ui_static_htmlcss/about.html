About GrandStay

Hospitality built around comfort and simplicity.

Our Story

GrandStay is a fictional hotel created as a beginner-friendly static HTML and CSS project.

The UI demonstrates semantic HTML elements such as header, nav, main, section, article and footer, together with CSS flexbox and responsive design.

There is no backend or booking functionality yet. It is intentionally focused on building a clean frontend foundation.

Our Promise

Comfortable rooms, friendly service and a simple experience from check-in to check-out.
